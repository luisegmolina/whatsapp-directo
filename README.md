# WhatsApp Directo

Página simple para abrir un chat de WhatsApp con cualquier número sin guardar el contacto.

- Elige el país (código), escribe el número y, si quieres, un mensaje.
- Abre el chat directo en WhatsApp (`wa.me`).
- Instalable como app en el celular (PWA): manifiesto + service worker + iconos.

## Publicación

Sitio estático en Render (plan gratuito, no se duerme: no hay servidor, solo archivos estáticos).

- Repositorio: https://github.com/luisegmolina/whatsapp-directo
- `index.html` — la página
- `manifest.webmanifest` — manifiesto PWA
- `sw.js` — service worker
- `icon.svg` — icono (SVG, válido para el manifiesto PWA)
